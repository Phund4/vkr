Новый поток

Полный URL публикации: …/stream_id. Stream ID должен совпадать с последним сегментом rtsp_url в конфиге router (в docker по умолчанию cam-01 … cam-04 — см. services/router/config.cameras.docker.yaml). Иначе MediaMTX примет поток, но router не читает его — метрики конвейера в Grafana останутся пустыми. Поднимите профиль apps (router, ml-serving, analytics …), иначе метрик pipeline не будет.

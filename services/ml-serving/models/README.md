# Модели для ml-serving

- **`winners.json`** — пути к чекпойнтам относительно каталога сервиса (`SERVING_ROOT`, по умолчанию корень `ml-serving` в образе: `/app`).
- Файлы весов кладите в **`../artifacts/.../best.pt`**, как в `winners.json`, либо задайте **`ACCIDENT_CKPT`** и **`CONGESTION_CKPT`** (абсолютный путь или относительно `SERVING_ROOT`).

Без файлов `*.pt` сервис стартует, но эндпоинт `/v1/process` вернёт 503 до появления весов.
